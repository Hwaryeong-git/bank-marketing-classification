# 데이터 준비

코드잇 스프린트 미션 12에서 제공된 `bank_marketing.csv`를 이 폴더에 둡니다.

- 경로: `data/bank_marketing.csv`
- 크기: 45,211행, 16열
- 정답: `y` (`yes`: 가입, `no`: 비가입)
- 입력: 나이, 직업, 금융 상태, 연락 정보 등 15개 열
- 원본 CSV는 저장소에 포함하지 않습니다.

수업에서 제공된 파일을 그대로 사용해야 저장된 결과와 같은 조건으로 실행할 수 있습니다. 이름이 비슷한 다른 Bank Marketing 데이터는 열 구성과 행 수가 다를 수 있습니다.
